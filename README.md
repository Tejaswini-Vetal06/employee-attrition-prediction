# 💼 RetainIQ — AI-Powered Employee Attrition Prediction & HR Analytics Platform

An enterprise-grade Workforce Intelligence and Employee Attrition Prediction web application built with **Python 3.11+**, **Streamlit**, **Scikit-learn**, and **Plotly**. RetainIQ empowers HR leadership to uncover multi-dimensional workforce patterns, evaluate probabilistic turnover risk, and take proactive, human-centric retention actions.

---

## 🌟 Executive Summary & Ethical Disclaimer

> [!IMPORTANT]
> **Probabilistic, Not Deterministic:** All predictions generated by RetainIQ represent statistical estimates based on historical employment dynamics. Predictions must **never** be used as the sole basis for hiring, compensation, promotion, discipline, or termination.
> 
> **Non-Discrimination Policy:** Protected demographic characteristics (including age, gender, race, and marital status) must never be utilized as criteria for adverse employment actions. All retention initiatives require confidential, supportive human review.

## 🚀 Key Modules & Capabilities

RetainIQ is organized into 6 dedicated, modular analytics portals:

1. **📊 Executive Dashboard (`pages/1_Executive_Dashboard.py`)**
   - High-level KPIs: Active Cohort, Historical Attrition Rate, Retained Count, Average Tenure, Mean Income.
   - Dynamic multi-dimensional filtering across Department, Job Role, and Overtime Status.
   - Interactive Plotly visualizations: Department volume comparisons, Job role attrition velocities, Overtime exposure, and Age-vs-Tenure scatterplots.
   - Clear distinction between retrospective historical records and predictive model forecasts.

2. **🔍 Exploratory Data Analysis (`pages/2_Exploratory_Analysis.py`)**
   - Dataset hygiene audits: Missing value detection, duplicate checks, and attribute schema profiling.
   - Target class imbalance diagnostics (~1:4 ratio).
   - Cross-tabulation bar charts across categorical features.
   - Interactive feature histograms with box plots and a full Pearson correlation matrix for numerical attributes.

3. **🎯 Individual Attrition Prediction (`pages/3_Attrition_Prediction.py`)**
   - Streamlined 3-column input form covering personal details, compensation, and workplace engagement.
   - Pre-loaded benchmark archetypes (High Retention, Moderate Risk, Elevated Risk) for instant testing.
   - Real-time probability percentage output with color-coded risk tiers (*Low*, *Moderate*, *High*).
   - Dynamic classification threshold slider calibrated to validation Youden's J statistic.
   - One-click exportable **Prediction Audit Report** (JSON).

4. **📈 Model Performance & Benchmarking (`pages/4_Model_Performance.py`)**
   - Rigorous benchmarking of **Logistic Regression**, **Random Forest**, and **Gradient Boosting**.
   - 5-Fold Stratified Cross-Validation on training folds to completely prevent data leakage.
   - In-depth evaluation: ROC-AUC, PR-AUC, Precision, Recall, F1-Score, and Accuracy.
   - Interactive ROC and Precision-Recall discrimination curves.
   - Dynamic confusion matrix with customizable operating threshold slider.
   - Clear architectural explanation of why raw accuracy fails on imbalanced workforce data.

5. **💡 Model Explainability & Governance (`pages/5_Model_Explainability.py`)**
   - Intrinsic global feature importance and directional coefficients (risk elevation vs. protective factors).
   - Model-agnostic Permutation Feature Importance evaluated on held-out test data.
   - SHAP (SHapley Additive exPlanations) sample value insights.
   - Plain-English operational translations for top attrition drivers (e.g., Overtime, Compensation, Managerial stability).
   - Regulatory safeguards and non-discrimination reminders.

6. **📁 Data Management & Pipeline Ops (`pages/6_Data_Management.py`)**
   - Secure CSV ingestion with in-memory validation against the 35-column IBM HR schema.
   - Clear separation: datasets without target columns are restricted to inference only.
   - Export sanitized, standardized CSV copies.
   - Deterministic Synthetic Demo Dataset generator (seed `42`).
   - One-click model retraining with instant pipeline persistence and cache invalidation.

## 📦 Setup & Installation

### 1. Clone Repository & Create Virtual Environment

```bash
# Clone repository
git clone https://github.com/<your-username>/employee-attrition-prediction.git
cd employee-attrition-prediction

# Create isolated Python virtual environment
python -m venv venv

# Activate virtual environment
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# macOS / Linux:
source venv/bin/activate
```

### 2. Install Dependencies

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Dataset Configuration

- **Default Demo Mode:** The system automatically initializes a deterministic 1,470-record synthetic dataset (`seed=42`) formatted identically to the IBM HR Analytics schema.
- **Official Enterprise Dataset:** To use the standard IBM HR dataset, place `WA_Fn-UseC_-HR-Employee-Attrition.csv` directly into the `data/` directory:
  ```bash
  data/WA_Fn-UseC_-HR-Employee-Attrition.csv
  ```
  The platform will automatically recognize and switch to the enterprise dataset on next load.

### 4. Train Models & Generate Artifacts

```bash
python -m src.train
```

*Output summary:*
```
Initiating model training and cross-validation...
Training Complete!
Selected Model: Logistic Regression
Validation ROC-AUC: 0.7713
Test ROC-AUC: 0.7719
Optimal Threshold: 0.418
Artifacts saved to models/
```

### 5. Run the Pytest Test Suite

```bash
pytest -v
```

All 18 unit and smoke tests will verify schema integrity, zero-leakage preprocessing, metric validity, and inference bounds.

### 6. Launch the Streamlit Web Application

```bash
streamlit run app.py
```

The application will start locally at `http://localhost:8501`.

## 🌐 Streamlit Community Cloud Deployment

1. Push this repository to GitHub (see Git commands below).
2. Visit [share.streamlit.io](https://share.streamlit.io) and log in with GitHub.
3. Click **"New App"**.
4. Select your repository and branch (`main`).
5. Set **Main file path** to:
   ```text
   app.py
   ```
6. Click **"Deploy!"**.
   - Dependencies from `requirements.txt` will install automatically.
   - The platform includes the self-generating fallback data and pre-trained model artifacts, ensuring immediate zero-configuration startup.
